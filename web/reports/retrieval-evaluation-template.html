01 / SAME QUESTIONS, DIFFERENT RETRIEVAL

얼마나 정확한 근거에 도달했나

Hit는 정해진 근거를 찾았는지, MRR은 첫 관련 근거가 얼마나 앞에 왔는지 봅니다. 논문 단위와 실제 근거 chunk 단위를 구분합니다.

검색 구성Source Hit@5Chunk Hit@5Chunk MRR@5모든 근거 그룹@5중앙 지연

위 Hit·MRR은 items stream의 any-hit 기준, 모든 근거 그룹은 chunk 기준입니다. 분모는 지원 가능한 300건입니다. 세부 지표 표에서 두 stream과 다른 k를 함께 확인할 수 있습니다.

평가 데이터의 해석

300건은 난이도별 75건씩, 언어별 150건씩 구성했습니다. 부족한 근거를 묻는 180건과 모호한 질문 20건은 검색 점수의 경계를 시험합니다.

qrels는 사전에 지정한 근거의 일부입니다. Hit 실패가 곧 corpus에 관련 근거가 전혀 없다는 뜻은 아닙니다. 이 실험은 생성 답변의 정답률이나 Pass@k를 측정하지 않습니다.

02 / RELEVANCE HAS A BOUNDARY

없는 답에 낮은 점수를 주는가

calibration에서 정상 질문 TPR ≥90%를 만족하는 가장 높은 threshold를 고정했습니다. 같은 threshold를 test에 적용합니다. relevance score는 답변 가능성의 확률이 아닙니다.

검색 구성 / 점수AUROCAP정상 TPROOD FPRGrey-zone FPR진단 gate

binary 분모 480건: supported 300 + insufficient 180. 모호한 20건은 제외합니다. OOD 50건, grey-zone 100건, in-domain missing 30건을 구분합니다. AP는 이 challenge set의 구성 비율에 영향을 받습니다.

높은 relevance는 부분적으로 관련된 자료를 찾았다는 뜻일 수 있습니다. 빠진 수치·조건·revision까지 답할 근거가 생기지는 않습니다. 현재 API의 실제 답변·abstention 정책은 이 검색 실험에서 평가하지 않았습니다.

선택한 구성의 점수 분포

경계 유형질문 수Threshold 이상비율해석

각 그림은 같은 구성 안에서 같은 score 축을 사용하며, 높이는 그룹별 빈도에 맞춥니다. 서로 다른 RRF·reranker score의 절댓값을 직접 비교하지 않습니다. 모호한 질문은 관련 자료에 높은 점수를 받아도 오류로 간주하지 않습니다.

  5. 05 / READ정본 확인 · 반환현재 revision·role·purpose 확인. 원문 source chunk와 추적 정보를 반환.

재현과 원자료

원문 열람 권한과 source corpus가 있어야 live 검색을 재실행할 수 있습니다. 공개된 metadata journal로는 이 보고서의 지표를 다시 계산할 수 있습니다.

성립하는 범위와 한계

  • test와 calibration의 질문·intent·근거 material을 분리했습니다. 문맥 생성에는 평가 질문·label을 제공하지 않았습니다.
  • 동일 자료·유사 intent의 변형 질문은 독립 표본이 아닙니다. intent-cluster bootstrap과 그룹 수를 함께 기록합니다.
  • 고정 corpus 안의 근거 유무를 평가했습니다. 일반적인 세계 지식의 참·거짓 판정이 아닙니다.
  • 이 결과는 검색 실험입니다. HAT committee의 설계 판정, B300 성능, 생성 답변 품질을 검증한 결과가 아닙니다.

실행 기록

최초 schema 호환 오류 실행은 무효 run으로 보존하고 점수 비교에서 제외했습니다. HTTP 실행 성공과 검색 진단 gate 통과 여부를 분리합니다.

참고한 공식 방법과 모델

Anthropic Contextual Retrieval의 chunk-specific LLM context를 embedding과 BM25에 적용했습니다. 논문의 개선 수치를 이 실험 결과로 사용하지 않습니다.

Qwen3 Reranker와 DeepInfra API를 사용하며, 사내 호환 HTTP endpoint는 환경 설정으로 연결할 수 있습니다.
